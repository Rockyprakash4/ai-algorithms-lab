# AI Algorithms Lab

A collection of Python implementations covering core Artificial Intelligence concepts, search strategies, probabilistic reasoning, expert systems, and natural language processing.

## 📂 Repository Contents

* **`AdversarialSearch.py`** — Implementation of adversarial search algorithms (such as Minimax / Alpha-Beta Pruning) for two-player games.
* **`BasicImageProcessing.py`** — Foundational computer vision and image manipulation techniques.
* **`BayesianNetwork–StudentPass.py`** — Probabilistic graphical model predicting student pass outcomes using Bayesian inference.
* **`GenerativeAIandPromptEngineering.py`** — Practical examples demonstrating generative AI workflows and prompt engineering techniques.
* **`MovieRecommendation.py`** — Recommendation engine filtering and suggesting movies based on user preferences or similarity metrics.
* **`Rule-BasedMedicalExpertSystem.py`** — Knowledge-based expert system utilizing logical `if-then` rules for basic medical diagnosis.
* **`SentimentAnalysisofReviews.py`** — Natural Language Processing (NLP) script for classifying text reviews into positive, negative, or neutral sentiments.
* **`UninformedandInformedSearch.py`** — Implementations of classic pathfinding algorithms (e.g., BFS, DFS, A*, Greedy Best-First Search).
